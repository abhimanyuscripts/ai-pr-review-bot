# Contributing

1. Create a branch from `main` (`feat/...`, `fix/...` or `docs/...`).
2. Run the tests before pushing: `python3 -m unittest discover -s tests -v`.
3. Open a pull request. The AI PR Review Bot will comment with a summary, risk level and suggested tests within a minute.
4. A human reviewer still approves before merging. The bot's review is advice, not a gate (unless `FAIL_ON_HIGH_RISK` is turned on).
